ABOUT HTML COMMENTS

HTML comments are notes written directly into the source code that web browsers completely ignore. They allow developers to document code, leave reminders, or temporarily disable sections of markup without deleting them. Because they are ignored by the parser, they do not appear on the front end of the rendered webpage.

Uses of comments

To explain how complex a block of code is
To nullify a part of the code you nomore want to show on the frontend
Can also be used to test various parts of a code
